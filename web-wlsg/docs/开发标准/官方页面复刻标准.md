# 官方页面复刻标准

最后更新：2026-07-12

## 1. 使用方式

用户先在 Codex 内置浏览器中打开需要复刻的官方《武林三国》页面，然后发出类似指令：

> 按照官方页面复刻标准完成当前页面。

AI 读取本文档后，直接观察浏览器当前实际可见页面并完成复刻。Hash、URL 名称和菜单名称只作为辅助信息；如果它们与实际画面不一致，以当前可见画面为准。

本标准可以重复用于资源、城池、军事、征兵、地图、联盟、排行、活动等页面，不再为每个页面单独编写版本开发文档。

## 2. 单次任务范围

- 一次只复刻浏览器当前打开的一个页面或一个明确弹窗。
- 包含当前页面直接可见的标签、表格、卡片、按钮、说明、状态和必要悬停效果。
- 复用已经完成的公共外壳，不重新制作顶部、导航和右侧栏，除非当前参考页面明确展示了它们的新状态。
- 不顺带开发同一导航下的其他页面。
- 不在页面复刻阶段接入新的真实业务 API。
- 可以使用集中管理的演示数据呈现页面完整结构，但必须明确隔离，不能冒充真实玩家数据。

如果页面必须通过一个简单的页内操作才能看到完整布局，AI 可以执行只读导航、切换标签或展开面板；不得提交会改变官方账号或游戏数据的操作。

## 3. 参考采集

开始开发前必须观察并记录：

- 当前页面标题、一级导航、二级导航和选中状态。
- 主内容区与右侧栏的宽度、高度和位置关系。
- 表格、卡片、按钮、输入框、提示框和分页结构。
- 字体大小、文字颜色、背景、边框、阴影、间距和对齐方式。
- 页面正常态、空状态、禁用态、悬停态和选中态。
- 当前视口未完整显示的纵向内容；必要时滚动观察完整页面。
- 页面使用的图片、图标、背景切片和装饰资源。

不得只根据记忆、URL 或单张局部截图推测页面。

## 4. 官方资源规则

- 可以采集当前页面需要的官方公开图片、图标、背景和界面切片。
- 资源保存到 `web-wlsg/public/` 或 `web-wlsg/src/assets/` 的清晰分类目录。
- 页面运行不得依赖官方图片热链。
- 新资源必须在 `docs/官网资源来源.md` 中记录本地文件、原始 URL、用途和采集日期。
- 不采集账号凭据、Cookie、聊天内容、玩家隐私数据或与当前页面无关的大批量素材。
- 资源缺失或不适合直接使用时，先使用统一占位或现有风格资源；不得错误套用含义不同的图片。

## 5. 实现标准

### 5.1 布局与组件

- 继续使用已经确认的 `997px` 固定桌面画布。
- 页面必须放入现有公共主内容区，不推翻公共外壳。
- 重复结构使用 Vue 组件和数据驱动渲染，不复制大量静态 HTML。
- 页面的列表、卡片和网格不得写死为参考截图中的固定数量。
- 内容增加时按照《武林三国》风格自然扩展行列、分页或内容高度，不允许截断、覆盖或丢失。
- 当前页面特有样式应限定作用域，不能污染已经验收通过的其他页面。

### 5.2 视觉还原

- 优先还原整体比例、区域位置和信息密度，再处理局部装饰。
- 颜色、边框、背景切片、字体层级、按钮尺寸和间距应与当前官方页面保持一致。
- 默认态、悬停态、选中态、禁用态和展开态必须可辨认。
- 页面不使用与现有暗红、黑色、铜金色体系冲突的现代扁平风格。
- 不因为演示文字长度变化产生明显跳动、遮挡或横向溢出。

### 5.3 演示数据

- 演示数据集中维护，不散落在多个组件中。
- 演示数据只用于展示页面结构和交互状态。
- 同类数据至少覆盖零值、正常值、较长文字和多项列表情况。
- 如果页面结构允许同类项目无限增加，应使用额外演示项验证扩展布局。

## 6. 禁止事项

- 不修改 Hero3 后端、数据库、OpenAPI、原 `web` 或 `admin`。
- 不接入未经用户要求的 API。
- 不执行官方站点上的建造、征兵、购买、发送、删除或其他写操作。
- 不伪造“已经接入”的真实功能。
- 不为了当前页面修改与它无关的已验收页面。
- 不创建新的版本编号开发文档。

## 7. 验收标准

### 7.1 视觉验收

- 当前页面的导航、结构、内容顺序和主要交互与官方可见页面一致。
- 在 `1280 × 800` 和 `1440 × 900` 下，`997px` 画布稳定居中。
- 不存在新增的非预期横向滚动、内容遮挡、文字溢出和布局跳动。
- 所有新增图片加载成功，页面不依赖官方热链。
- AI 提供两个目标视口的本地截图，并与官方当前页面对照检查。

### 7.2 工程验收

- `pnpm build` 通过，包含 TypeScript 类型检查。
- 页面结构、映射和关键交互具有与风险相匹配的自动测试。
- 浏览器控制台不存在由本次任务引入的警告和错误。
- 新增文件顶部和功能方法具有符合仓库规则的中文说明注释。
- 中文 README 和资源来源记录按实际变化更新。
- 不存在 `web-wlsg/` 作用域外的代码修改。

### 7.3 用户验收

- AI 完成开发、自检和截图后必须停止。
- 用户进入本地页面亲自检查视觉、布局和演示交互。
- 用户未明确确认页面复刻通过前，不得接入该页面 API，也不得开始下一个页面。
- 用户提出问题时只修正当前页面，修正后重新等待验收。

## 8. 完成报告

AI 最终只需向用户报告：

- 本次复刻的官方页面名称和实际范围。
- 新增或修改的主要组件。
- 是否采集官方资源及来源记录位置。
- 构建、测试、控制台和两档视口检查结果。
- 当前明确未实现的真实业务能力。
- 页面已经停在等待用户视觉验收状态。
