# 司马懿特性更新开发文档

最后更新：2026-07-22

## 1. 当前正式设计

### 1.1 疑兵偷袭 `yibing_touxi`

- 阶段：进攻、防守或增援的战斗前。
- 默认触发概率：35%，GM 可配置 `triggerChance`。
- 默认真实伤亡比例：35%，GM 可配置 `effectRate`。
- 效果：按敌方原始出战全军逐兵种直接形成真实伤亡，不读取攻击、防御、武将属性、城墙或其他加成。
- 顺序：先从敌方原始出战兵力扣除真实伤亡，剩余兵力再进入正常攻防计算。
- 旧参数 `maxAffectedRate` 已废止；真实减员只由 `effectRate` 决定。

### 1.2 谋定后发 `mouding_houfa`

- 阶段：防守或增援的战斗前；主动进攻无效。
- 默认触发概率：35%，GM 可配置 `triggerChance`。
- 默认防御加成：35%，GM 可配置 `defenseBonusRate`。
- 效果：司马懿所率全军步兵防御和骑兵防御增加 35%，按现有核心整数规则形成逐兵种实际修正。
- 旧版“防守时必定降低敌方攻击 10%”的参数、文案和专属验收全部废止。

## 2. 组合与核心边界

- 两项特性独立判定；防守或增援时可以同时触发，也可以只触发任意一项或均不触发。
- 同时触发时，时间线固定为“疑兵偷袭”在前、“谋定后发”在后。
- 战前处理完成后，将剩余兵力和加成后的防御交给现有战斗核心重新计算战力、胜负与核心兵损。
- 不修改稳定战斗核心的校验、胜负公式或兵损公式；本轮只通过既有特性事件和应用层编排接入。
- 真实伤亡必须进入最终战损、权威返程或库存、经验和双方战报，不能只改变战力快照。

## 3. GM 与旧配置迁移

正式配置位于 `go/config/generals.json`。GM 可配置：

| 特性 | 参数 | 默认值 |
| --- | --- | --- |
| 疑兵偷袭 | `triggerChance` | `0.35` |
| 疑兵偷袭 | `effectRate` | `0.35` |
| 谋定后发 | `triggerChance` | `0.35` |
| 谋定后发 | `defenseBonusRate` | `0.35` |

配置归一化必须删除疑兵偷袭旧 `maxAffectedRate`，并把谋定后发旧 `effectRate` / `attackReductionRate`、`enemy_army` 和仅 `defender` 方向迁移为当前加防参数、`self_army` 及 `defender + reinforcement`。

## 4. 战报要求

- 疑兵偷袭：显示触发概率、设计真实伤亡比例和逐兵种 `preBattleAffected` 实际伤亡。
- 谋定后发：显示触发概率、设计防御加成及逐兵种 `infantryDefenseModifiedUnits`、`cavalryDefenseModifiedUnits` 实际整数变化。
- 主守将结果归属 `defender`，援军结果归属真实 `reinforcement` 玩家和司马懿，不能挂到主守将名下。
- 未命中的特性不进入 `TraitTriggered`、旧结果或标准时间线，但参战将领拥有快照仍保留两项特性。
- `web` 与 `web-wlsg` 必须使用同一后端权威结果展示，不自行按百分比重算。

## 5. 验收矩阵

| 场景 | 疑兵 | 谋定 | 必须验证 |
| --- | --- | --- | --- |
| PVP 主动进攻 | 命中/未命中 | 必须无效 | 原始敌军真实减员、剩余兵力战力、返程、经验、双方战报 |
| PVP 主守城 | 命中/未命中 | 命中/未命中 | 四种独立组合、顺序、攻防战力、最终库存与经验 |
| PVP 增援 | 命中/未命中 | 命中/未命中 | 四种独立组合、联盟战力、主守军/援军分损、真实归属 |
| NPC 主动进攻 | 命中/未命中 | 必须无效 | NPC 真实扣兵、玩家返程、经验和战报 |
| 黄巾守城 | 命中/未命中 | 命中/未命中 | 城墙基线、剩余黄巾战力、加防后守军战力、库存与战报 |
| 轮回副本 | 按攻守方向 | 仅防守有效 | 正式全特性矩阵不越权、不漏触发 |
