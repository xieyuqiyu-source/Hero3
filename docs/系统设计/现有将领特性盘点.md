# 现有将领特性盘点

最后更新：2026-07-23

## 1. 文档目的

本文档用于盘点项目中当前已有的将领特性，作为后续“将领特性短期治理”的基础资料。

当前盘点来源：

- `go/config/generals.json`
- `go/internal/core/general/traits/`
- `go/internal/app/game/general_effects.go`
- `go/internal/app/game/general_growth.go`

本文档只描述“现在项目里已有的特性长什么样”，不代表所有特性都已经完成验收。

曹操、郭嘉和刘备等已完成逐将治理的当前权威规则，以各自的“特性更新开发文档”为准。本文后半部分保留的旧数值验收记录只用于追溯当时版本，不得覆盖当前配置。

刘备旧版“仁德复活 50% + 仁主守护返还 10% + 单场 10000 上限”已在 2026-07-23 废止。当前规则只以 [刘备特性更新开发文档](./刘备特性更新开发文档.md) 和本文件第 5 节现行表格为准。

## 2. 当前整体结构

当前每个启用将领基本采用“双特性结构”：

- `specialTrait`：特殊特性，偏主动触发、战前削弱、战后伤害、减损、行军、掠夺等效果。
- `bonusTrait`：加成特性，偏攻防、兵种、速度、减损、产量等效果。

将领属性点中，“武力”对应系统 key：

```text
force
```

当前换算规则：

```text
1 点 force = 2% 攻击加成
GeneralStatPercentPerPoint = 0.02
最终进入 StatAttackBonus
```

这类属性加成属于被动属性装配，不应当作为战斗中触发的特性写入战报。

## 3. 已注册特性类型

当前特性大致分为以下几类。

| 类型 | 触发阶段 | 典型效果 | 示例 |
| --- | --- | --- | --- |
| 战前削弱 | `before_battle` | 战斗开始前减少敌方参战兵力 | 疑兵偷袭、水淹七军、张辽震慑全军、奇门遁甲 |
| 战前攻防修正 | `before_battle` | 修改本次战斗单位攻击、防御 | 武圣破军、江东固守、魏武统御 |
| 战斗结算后追加伤害 | `after_combat_resolve` | 修改 `CombatResult`，追加敌方损失 | 火攻、西凉突击、老当益壮、火烧联营 |
| 战斗结算后减损 | `after_combat_resolve` | 降低己方本场损失 | 龙胆救援 |
| 战斗结束后复活 | `after_battle` | 按本场真实阵亡把部分兵力加回 | 仁主守护、鬼才遗策 |
| 行军速度 | `march_create` | 缩短出征或增援行军时间 | 七进七出、白衣渡江、白衣急行、快如闪电 |
| 征兵消耗 | `recruit_cost` | 降低征兵资源消耗 | 王佐之才 |
| 掠夺收益 | `plunder_resolve` | 提高或降低掠夺收益 | 锦帆劫掠、江东号令 |
| 特性压制 | `after_combat_resolve` | 压制敌方若干特性触发 | 卧龙奇谋、苦肉计 |
| 被动属性 | 装配阶段 | 进入将领最终四维或 Modifier，不进战报触发 | 天神下凡、神鬼之才、仁德天下 |

## 8. 首轮治理结果

截至 2026-07-19，已完成以下基础修复和自动化验证：

### 8.1 完整性矩阵

以下统计必须区分“代码存在”“主流程验收”和“全部场景完成”，不能互相替代：

| 验收层级 | 当前进度 | 说明 |
| --- | --- | --- |
| 正式 ID、后端注册和双前端中文名称 | 50/50 | 只能证明特性可识别，不代表实际战斗有效 |
| 正式配置参数锁定 | 50/50 | 每项正式特性的归属、场景、参数和核心可消费效果均已锁定 |
| 按将领完成代表性真实主流程 | 25/25 | 每名将领至少有资源、征兵、行军、PVP、NPC、黄巾、扫荡或增援中的权威状态与战报对账；这不代表每项特性的全部场景都已完成 |
| 本轮定义的严格治理矩阵 | 50/50 | 50 项正式特性均已具备注册、正式配置、真实效果、战报结果、后端业务测试和双前端中文展示证据；随机项另有合法未命中与错误场景证据 |
| 开放式全组合治理 | 持续维护 | 新增玩法、修改配置或出现新组合时重新开启对应矩阵；它不是可以一次穷举完的固定验收项 |

代表性主流程已经验收的 25 名将领：曹操、司马懿、甄宓、许褚、典韦、夏侯渊、张辽、郭嘉、荀彧、刘备、关羽、张飞、诸葛亮、赵云、马超、黄忠、魏延、孙权、孙策、周瑜、陆逊、吕蒙、太史慈、甘宁、黄盖。

因此截至 2026-07-20，本轮短期治理可以记为“代表性将领主流程 100%，正式特性配置与真实收益 100%，本轮定义的严格治理矩阵 100%”。这表示当前 25 名将领、50 项正式特性和已列玩法入口的既定验收项已经收口；后续新增玩法、调整配置或发现新的跨模块组合时，仍按持续治理提示词重新打开对应项目，不能把本轮结论当作永久豁免。

- 增加 `allowedSides`、`allowedScenes`、`requiredOutcome`，由核心事件总线统一约束触发方、场景和胜负条件。
- 周瑜火攻已验证进攻触发、防守不触发；火攻战报追加伤害已与真实守军扣兵同值校验。
- 孙权江东固守已验证进攻无效、防守增加 50% 防御，并在 PVP 战报中归属防守将领。
- 赵云龙胆救援限制为防守或增援，主动进攻不会误触发；真实 PVP 对照验证守城主将和赵云所在援军批次均按最终损失降低 20%，实际剩余兵力、攻方战报、守方战报和援军独立战报使用同一逐兵种减损值。两个前端同时展示后端返回的设计减损比例和真实逐兵种减损，不自行按比例重算。
- 太史慈信义勇烈已从当前守方核心不消费的援军攻击改为核心可结算的援军两类防御 `+10%`，只修改太史慈所在援军批次；真实 PVP 开关对照验证防御战力由 `1010` 提升到 `1110` 且实际兵损下降，进攻方、防守方和援军方三份战报均记录步防、骑防实际 `+1`。主动进攻与主城守军继续由 `allowedSides=[reinforcement]` 和反向测试锁定为无效。魏延奇兵绕后限制为进攻方；甘宁两项能力限制在掠夺场景。
- 马超天神下凡改为被动 `force +20`，进入 `effectiveStats` 和攻击 Modifier，不进入 `TraitTriggered`。
- 仁德已验证 PVP 中 `返回兵力 = 出动 - 阵亡 + 复活`，特性结果同时记录复活总数和逐兵种 `revivedUnits`，与回城后的真实兵力一致。

## 9. 后续使用方式

后续每次治理将领特性时，应先从本文档找到对应特性，再按《将领特性短期治理开发文档》的检查表逐项验收：

- 是否注册。
- 是否配置到将领。
- 是否能触发。
- 是否真实改变战斗输入、战斗结果或真实状态。
- 是否进入正确战报字段。
- `web` 和 `web-wlsg` 是否同步展示。
- 是否补充正反测试。
