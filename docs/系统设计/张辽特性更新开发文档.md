# 张辽特性更新开发文档

## 1. 现行设计

### 震慑全军

- 稳定 ID：`weizhen_zhenhe`，只保留 ID 兼容，旧名称“威震震慑”不再使用。
- 类型：主动进攻战斗前概率特性；防守、增援、黄巾守城和轮回防守波无效。
- 默认概率：`35%`，由 GM 的 `triggerChance` 配置。
- 默认效果：按敌方本次参战总兵力精确计算 `25%` 溃逃人数，由 GM 的 `effectRate` 配置。
- 结算：溃逃兵从本轮参战军队中临时抽离，不进入攻击、防御、核心兵损和经验计算；战斗结束后完整保留在敌方库存或返程队伍中。
- 取整：总溃逃人数使用 `floor(敌方参战总兵力 × effectRate)`，再稳定分配到各兵种，避免逐兵种取整导致总数少算。
- 战报：命中时记录 `fledUnits`、`returnedUnits` 和兼容字段 `suppressedUnits`；玩家页面只展示“本场溃逃兵力”和“战后返回兵力”。未命中不生成触发结果。

### 威震逍遥

- 稳定 ID：`weizhen_xiaoyao`。
- 类型：主动进攻战斗前概率特性；防守和增援无效。
- 默认概率：`60%`，由 GM 的 `triggerChance` 配置。
- 默认效果：张辽所率骑兵攻击增加 `35%`，由 GM 的 `attackBonusRate` 配置。
- 取整：逐兵种攻击使用现有整数属性规则计算；例如魏骑兵攻击 `14` 提升为 `19`，战报记录实际 `+5`。
- 战报：命中时记录设计概率、设计比例和逐兵种实际攻击变化；未命中不生成触发结果。

## 2. 组合与结算顺序

1. 仅在张辽作为主动进攻方参战时进入两项特性判定。
2. 震慑全军和威震逍遥独立判定，可以同时命中、单项命中或同时未命中。
3. 震慑命中时先从敌方参战军队临时抽离溃逃兵。
4. 威震逍遥命中时修改张辽所率骑兵的本场攻击。
5. 使用最终参战兵力和最终攻防属性进入现有战斗核心。
6. 结算真实阵亡、经验和胜负后，溃逃兵按原兵种完整保留。

不修改战斗核心校验；特性适配层只负责准备本场参战军队和结构化结果。

## 3. GM 与旧配置迁移

- 震慑全军公开 `triggerChance`、`effectRate`；删除重复的 `maxAffectedRate`、`maxAffectedCount`，避免旧上限截断现行比例。
- 旧正式值 `effectRate=0.20` 自动迁移为 `0.25`；已有非旧默认值的 GM 自定义比例保留。
- 震慑全军强制归一化为 `scope=enemy_army`、`allowedSides=[attacker]`。
- 威震逍遥公开 `triggerChance`、`attackBonusRate`；旧配置缺少概率时自动补为 `0.60`，已有显式概率保留。
- 威震逍遥强制归一化为 `scope=self_army`、`targetUnitType=cavalry`、`allowedSides=[attacker]`。

## 4. 权威样本

1000 名魏骑兵主动进攻 1000 名蜀步兵并保留蜀国一级城墙时：

| 组合 | 攻防战力 | 进攻方阵亡 | 防守方阵亡 | 防守方最终保留 |
|---|---:|---:|---:|---:|
| 两项同时命中 | `19000 / 6120` | `199` | `750` | `250` 名溃逃兵 |
| 仅震慑全军命中 | `14000 / 6120` | `308` | `750` | `250` 名溃逃兵 |
| 仅威震逍遥命中 | `19000 / 8160` | `300` | `1000` | `0` |
| 两项同时未命中 | `14000 / 8160` | `464` | `1000` | `0` |

命中特性、双方战力、逐兵种兵力行、返程或守军库存和经验必须在双方战报中完全一致。

## 5. 验收矩阵

- 概率：两项同时命中、仅第一项命中、仅第二项命中、同时未命中。
- 方向：主动进攻有效；主将防守、援军和黄巾守城即使概率强制为 `100%` 也不得触发。
- 场景：真实 PVP、NPC、轮回进攻波以及错误方向适配。
- 溃逃：单兵种和混编总人数取整、实际参战战力、真实阵亡、经验、库存、返程与双方战报对账。
- 加攻：仅骑兵变化，非骑兵不变；战报使用后端逐兵种实际整数修正。
- 工程：后端全量测试、专项 `-race`、`web` 与 `web-wlsg` 测试和生产构建、Chrome 页面检查、文档、当天记忆及 `git diff --check` 全部通过。
