# <span style="color:#dc2626">Hero3 安全与权限规范</span>

最后更新：2026-06-25
## <span style="color:#dc2626">1. 认证</span>

- 玩家侧采用 JWT。
- 登录后 token 由前端保存并自动注入请求头。
- token 失效后应强制重新登录。

## <span style="color:#dc2626">2. 授权</span>

- 玩家接口必须校验存档归属。
- 账号接口必须校验账号归属。
- 管理接口必须使用管理员凭证。
- 不能只靠前端隐藏按钮判断权限。

## <span style="color:#dc2626">3. 高危接口</span>

以下类型接口要重点保护：

- 发资源
- 改金币
- 改配置
- 发信
- 删除存档
- 修改战斗或奖励规则

## <span style="color:#dc2626">4. 审计要求</span>

- GM 操作应保留日志。
- 货币变更应写流水。
- 重要操作要可追踪到账号和玩家。

## <span style="color:#dc2626">5. 风控基础要求</span>

- 管理接口要限频。
- 需要防止越权修改他人存档。
- 公开接口必须确认不泄露敏感状态。
- CORS 只允许配置中的来源。

## <span style="color:#dc2626">6. 当前实现约定</span>

- `X-Admin-Token` 仅用于管理后台。
- 玩家身份从 `Authorization: Bearer <token>` 读取。
- 所有玩家动作都应经过归属校验。
