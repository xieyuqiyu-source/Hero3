# Hero3 开发进度记录

## 2026-06-26 公告系统

### 本次目标

- 完成纯公告系统闭环，公告独立于信函系统。
- 公告不支持附件、不支持领取操作、不支持玩家回复。
- 支持 GM 创建、编辑、发布、下架公告。
- 支持玩家查看当前可见公告、详情和已读状态。

### 后端改动

- 新增 `Announcement`、`AnnouncementRead`、`AnnouncementPage`、`AnnouncementInput` 模型。
- 新增公告服务逻辑：
  - GM 创建草稿公告。
  - GM 编辑公告。
  - GM 发布公告。
  - GM 归档/下架公告。
  - 玩家获取可见公告列表。
  - 玩家获取公告详情。
  - 玩家标记公告已读。
- 玩家可见规则：
  - 只有 `published` 状态可见。
  - `startsAt` 未到不可见。
  - `endsAt` 已过期不可见。
  - 列表按 `pinned`、`priority`、`startsAt/createdAt` 排序。
- MySQL 新增独立表：
  - `announcements`
  - `announcement_reads`
- 内存仓储同步支持公告，保证无数据库模式可用。
- 公告未混入 `mails` 表或信函逻辑。

### 玩家 Web 改动

- 新增 `/notice` 公告页面。
- 侧边栏和移动端菜单新增公告入口。
- 公告未读数量通过独立公告接口加载，不依赖 `game/state` 重接口。
- 公告列表展示标题、类型、置顶、展示时间和已读状态。
- 点击公告打开详情弹窗，并调用已读接口。
- 页面保留 loading、错误、空状态和移动端宽度适配。

### GM Admin 改动

- 后台新增独立“公告管理”页面。
- 支持公告列表、新建、编辑、发布、下架和删除入口。
- 删除接口按后端软删除逻辑归档公告。
- 表单支持公告类型、置顶、优先级、开始时间和结束时间。
- 表单校验标题必填、正文必填、开始时间不能晚于结束时间。

### OpenAPI 改动

- 新增 `docs/openapi/paths/announcement.yaml`。
- 新增 `docs/openapi/schemas/announcement.yaml`。
- `docs/openapi/openapi.yaml` 挂载玩家端和 GM 端公告接口。
- `make openapi` 用于重新生成 `docs/openapi.bundle.yaml`。
