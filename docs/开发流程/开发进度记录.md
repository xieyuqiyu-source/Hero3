# Hero3 开发进度记录

## 2026-06-26 公告系统

### 本次目标

- 完成纯公告系统闭环，公告独立于信函系统。
- 公告不支持附件、不支持领取操作、不支持玩家回复。
- 支持 GM 创建、编辑、发布、下架公告。
- 支持玩家查看当前可见公告、详情和已读状态。

### 后端改动

- 新增 `Announcement`、`AnnouncementRead`、`AnnouncementPage`、`AnnouncementInput` 模型。
- 新增公告服务逻辑：
  - GM 创建草稿公告。
  - GM 编辑公告。
  - GM 发布公告。
  - GM 归档/下架公告。
  - 玩家获取可见公告列表。
  - 玩家获取公告详情。
  - 玩家标记公告已读。
- 玩家可见规则：
  - 只有 `published` 状态可见。
  - `startsAt` 未到不可见。
  - `endsAt` 已过期不可见。
  - 列表按 `pinned`、`priority`、`startsAt/createdAt` 排序。
- MySQL 新增独立表：
  - `announcements`
  - `announcement_reads`
- 内存仓储同步支持公告，保证无数据库模式可用。
- 公告未混入 `mails` 表或信函逻辑。

### 玩家 Web 改动

- 新增 `/notice` 公告页面。
- 侧边栏和移动端菜单新增公告入口。
- 公告未读数量通过独立公告接口加载，不依赖 `game/state` 重接口。
- 公告列表展示标题、类型、置顶、展示时间和已读状态。
- 点击公告打开详情弹窗，并调用已读接口。
- 页面保留 loading、错误、空状态和移动端宽度适配。

### GM Admin 改动

- 后台新增独立“公告管理”页面。
- 支持公告列表、新建、编辑、发布、下架和删除入口。
- 删除接口按后端软删除逻辑归档公告。
- 表单支持公告类型、置顶、优先级、开始时间和结束时间。
- 表单校验标题必填、正文必填、开始时间不能晚于结束时间。

### OpenAPI 改动

- 新增 `docs/openapi/paths/announcement.yaml`。
- 新增 `docs/openapi/schemas/announcement.yaml`。
- `docs/openapi/openapi.yaml` 挂载玩家端和 GM 端公告接口。
- `make openapi` 用于重新生成 `docs/openapi.bundle.yaml`。

### 验证项

- `cd go && go test ./...`
- `cd web && pnpm build`
- `cd admin && pnpm build`
- `make openapi`
- `git diff --check`

## 2026-06-26 PVP v1 与行军系统

### 本次目标

- 完成玩家攻击玩家第一版闭环。
- 玩家互攻必须创建行军队列，不再立即结算。
- 行军到达后统一结算双方状态、战损、掠夺和战报。
- GM 可配置行军时间和加速规则。

### 后端改动

- 新增 `PvpMarch`、`PvpMarchView`、`PvpTarget`、`MarchConfig` 等模型。
- 新增 `service_pvp.go`，集中处理目标列表、出征行军、行军加速和到期结算。
- MySQL 新增 `pvp_marches` 表；内存仓储同步支持行军持久化。
- 玩家攻击玩家会从攻击方 `army` 扣除出征兵力，创建 `marching` 状态行军。
- 发起攻击通过仓储组合操作事务化保存攻击方状态并创建行军，避免扣兵成功但行军未创建。
- `SettleDueMarches(now)` 作为统一结算入口，`game/state`、PVP 行军列表和军情列表会触发到期行军结算。
- 行军到达后读取双方最新状态，并先结算离线资源、建筑、征兵和加成过期，再执行战斗。
- 防守方 `army + garrisonArmy` 共同参战；战损按来源分别扣回主军队和驻防军队。
- 防守方无守军时攻击方直接胜利，不产生攻击方战损，并按存活负重掠夺资源。
- 到达结算通过仓储组合操作事务化保存双方状态、双方战报和 march resolved 状态。
- PVP 接入现有将领特性事件管线：
  - 战前特性可影响战斗军队。
  - 战后特性结果写入双方战报。
  - 甄宓跨阵营俘虏进入攻击方 `garrisonArmy`。
  - 刘备仁德复活结果写入战报。
- PVP 将领经验按击杀兵种口粮计算。
- 战报新增并使用 `defenderArmyUnits`、`defenderArmyLostUnits`、`defenderGarrisonUnits`、`defenderGarrisonLostUnits`、`defenderNoGuard` 等字段。

### 玩家 Web 改动

- PVP 入口放在地图页“玩家”tab，不新增独立征战导航。
- 玩家可在地图玩家 tab 查看可攻击玩家城池卡片，目标包含在线与离线玩家，但不暴露完整军队。
- 玩家可从主军队选择战斗兵种出征，不能选择驻防军队或非战斗兵。
- 发起攻击成功后展示行军结果，不显示即时战斗结果。
- 行军队列展示 outgoing / incoming、抵达时间、倒计时和状态。
- outgoing 行军显示出征兵力和加速按钮；incoming 行军显示“敌军来袭”但隐藏兵力。
- 加速后刷新倒计时、抵达时间和玩家城金状态。
- 军情列表支持 PVP 类型；战报详情支持 PVP 双方信息、主军/驻防损失、掠夺资源、防守无守军和将领特性结果。

### GM Admin 改动

- GM 配置页新增“行军配置”面板。
- 可配置最大行军时间、最短行军时间、速度换算倍率。
- 可配置加速开关、固定城金消耗、剩余时间倍率和加速后最短剩余时间。
- 已出发行军使用创建时固化配置，不受后续 GM 修改影响。

### OpenAPI 改动

- 新增 `docs/openapi/paths/pvp.yaml`。
- 新增 `docs/openapi/schemas/pvp.yaml`。
- `docs/openapi/openapi.yaml` 挂载 PVP 目标、攻击、行军列表、加速和 GM 行军配置接口。
- `BattleReport` schema 补充 PVP 主军/驻防拆分字段、无守军、特性和经验字段。
- 旧 `/api/v1/map/players/attack` 文档改为兼容入口，响应同 PVP 行军创建结果。
