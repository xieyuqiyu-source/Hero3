# Hero3 Web

`Hero3 Web` 是 Hero3 项目的前端工程，当前基于 `React + TypeScript + Vite` 搭建，用于承载三国题材策略网页游戏的浏览器端界面、交互与后续玩法原型。

生产环境固定发布到 `https://hero3.ccoos.cn/`，构建产物安装在服务器 `/var/www/hero3/web/`；不得与 `web-wlsg` 共用或互换发布目录。

## 技术栈

- React 19
- TypeScript
- Vite
- ESLint
- pnpm

## 目录结构

```text
web/
├── public/          # 静态资源
├── src/             # 前端源码
├── index.html       # HTML 入口
├── package.json     # 前端依赖与脚本
├── vite.config.ts   # Vite 配置
└── README.md        # 前端说明文档
```

## 本地开发

安装依赖：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm dev
```

构建生产版本：

```bash
pnpm build
```

代码检查：

```bash
pnpm lint
```

本地预览构建结果：

```bash
pnpm preview
```

## 项目说明

当前前端已承载账号、城池、军事、地图、副本、万象幻境等主要玩家界面。万象幻境入口位于 `地图 -> 万象幻境`，当前包含仙池垂钓、军营豪赌和天机轮转；其中军营豪赌和天机轮转的最终结果均以后端结算响应为准。天机轮转第二版前端展示 3 个竖向转轮、每轮 3 个可视格、固定 5 线和每线押注，总押注、中奖线、免费旋转、宝匣奖励与可兑换库存均来自后端响应。

军情战报详情页使用后端 `BattleReport.detail` 作为主契约，按来源、战斗动作、玩家视角和当前玩家结果拆分展示。列表支持全部、进攻、防守、协防、侦查、扫荡分类；详情页等待完整详情接口返回后再渲染，避免列表摘要闪现为错误兵力或内部 ID。增援参战方使用战前兵力快照展示“出动”，并在携带武将实际获得经验时于武将信息旁显示经验值；战斗特性按真实攻击、防守或增援方归属，旧黄巾防守战报也会在前端兼容纠正。公开分享 token 直接读取分享接口，登录状态不会先触发一次内部战报 404。
