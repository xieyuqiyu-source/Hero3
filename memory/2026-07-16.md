## 稳定用语

- “一键爆仓”：仅表示付费把木材、泥土、铁矿、粮食补满至当前容量。

## 轮回绝境完善

- 轮回绝境每波默认携带当前可用主将；主将不可用时回退到第一名空闲将领，玩家仍可改选其他将领或选择不携将。
- 随军将领区域展示后端返回的真实攻防加成与激活特性，不在前端虚构固定加成。
- 携将参与进攻或防守后，后端按本波实际击杀结算真实将领经验；前端显示本波获得经验，并在发生升级时显示升级前后等级。
- 新增 `POST /api/v1/dungeons/reincarnation/exit`：只允许已经结束的实例退出，操作幂等，保留历史副本、战报与已发放奖励；退出成功后前端回到层级选择。
- 修正轮回绝境重复动作的幂等判断顺序，先识别已处理的动作，再校验当前活动波次，避免网络重试被下一波状态误拒绝。
- OpenAPI、打包接口文档和 `web-wlsg` README 已同步上述接口、将领特性字段和页面行为。
