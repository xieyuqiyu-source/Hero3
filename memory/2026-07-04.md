# 2026-07-04 记忆

## 每日更新公告文案规则调整

- 用户明确要求自动发布公告不能直接展示代码修改、文件修改、提交标题或专业实现内容。
- 每日更新公告应面向玩家表达：这次更新了什么玩法、优化了什么体验、解决了什么游戏 BUG。
- 公告生成逻辑改为只用 git 提交范围判断是否有新版本，正文来源固定为 `announcements/daily/YYYY-MM-DD.md`，不再从 `memory/YYYY-MM-DD.md` 读取玩家公告内容。
- 自动公告正文改为受限 HTML 富文本排版，包含引导文、更新列表和说明；玩家端公告详情新增白名单 HTML 渲染，普通纯文本公告仍按换行展示。
- 文档同步更新 README、服务器部署文档和公告系统设计文档，明确每日公告只描述玩法/体验/BUG，不展示内部代码信息。
- `memory/YYYY-MM-DD.md` 继续记录较专业的开发内容，不适合直接做玩家公告来源；`announcements/daily/YYYY-MM-DD.md` 是唯一玩家公告源。
- 如果当天公告源不存在或没有 `## 玩家公告` 条目，即使有代码更新也不发布每日公告。
