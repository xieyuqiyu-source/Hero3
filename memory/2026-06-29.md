- Admin 配置页新增物品配置 JSON 校验/保存、玩家背包格子查询、物品流水筛选；原 GM 发物品继续可用。
- Admin 物品配置页继续补齐表单式新增/编辑流程：先选分类、品质，系统按分类展示 ID 前缀，GM 填后缀、名称、描述、堆叠、确认规则和效果 JSON；已有物品编辑时锁定 ID。
- 玩家端武将页背包改为格子展示，按品质显示颜色，使用高品质物品弹二次确认。
- 用户确认背包格子只显示小正方形本体，暂时使用 icon 占位；物品名称、品质、描述、使用和取消操作统一放到点击格子后的弹窗中，后续每个物品会单独设计图片。
- OpenAPI、README、Go README 已同步；`make openapi-bundle` 已重新生成打包文档。
- 修复存储层核心建筑投影和显式修复事务比较基准，旧玩家补齐核心建筑后会持久化到 `player_buildings`，此前阻碍全量存储测试的建筑测试已通过。
