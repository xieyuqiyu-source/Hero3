## 夏侯渊特性更新

### 决策

- 疾行奔袭是永久被动，不进行概率判定，也不作为战斗前触发项写入战报时间线；仅对夏侯渊所率骁骑营固定增加 18 点攻击和 5 点移动。
- 疾行奔袭在主动进攻、防守和增援中持续生效；攻击加成参与实际战力和兵损计算，移动加成参与真实行军时间计算。
- 盾阵防御仅在防守或增援战斗前判定，默认 60% 概率使所率全军步兵、骑兵防御增加 30%；主动进攻无效，概率和比例均可由 GM 配置。
- 两项能力性质不同：永久被动单独显示为“被动生效”，盾阵防御命中时才进入“将领特性触发”和战前计算记录。

### 实现

- 正式配置、特性目录和配置迁移统一到骁骑营攻击 `+18`、移动 `+5` 以及盾阵防御 `60% / +30%`，清理疾行奔袭旧百分比移速、最低行军时间和概率字段。
- 新增按目标兵种读取固定攻击、移动修正的后端能力；PVP、增援行军和战斗均使用同一将领快照中的实际被动数值。
- 盾阵防御继续复用标准战前防御修正，不修改核心校验；命中后重新计算全军防御战力和真实兵损，未命中及主动进攻均不产生效果。
- `web` 与 `web-wlsg` 同步特性元信息和战报展示；永久被动与概率触发分区，避免把疾行奔袭误报成一次战斗触发。
- 新增 `docs/系统设计/夏侯渊特性更新开发文档.md`，同步更新项目索引、文档目录、现有特性盘点、平衡设计和短期治理文档。

### 验收

- `go test ./... -count=1` 全量通过；夏侯渊专项使用 Go `-race -count=3` 通过。
- 真实 PVP 验证 100 骁骑营固定增加 1800 攻击战力、行军缩短且实际兵损变化；真实增援验证盾阵命中时防御战力由 1310 增至 1710，并减少实际损失。
- 盾阵防御覆盖命中、未命中、主动进攻无效、防守有效和增援有效；疾行奔袭覆盖目标兵种、非目标兵种、混编最慢速度及不进入触发时间线。
- `web` 236 项、`web-wlsg` 287 项测试全部通过，两个生产构建成功。
- 本机已安装 Chrome 使用真实账号进入同一夏侯渊存档：`web` 将领详情准确显示永久被动 `+18 / +5` 和盾阵 `60% / +30%`，`web-wlsg` 正常进入军事页；两边无控制台警告、错误或横向溢出。

## 张辽特性更新

### 决策

- 震慑全军仅在主动进攻战斗前独立判定，默认 35% 概率使敌方当前参战总兵力的 25% 溃逃；按全军总数向下取整后分配到各兵种，避免混编部队逐兵种取整造成少算。
- 溃逃兵不参与本次攻击、防御和兵损计算，不视为死亡、不提供经验，战后原样返回敌方部队；战报必须同时记录本场溃逃数量与战后返回数量。
- 威震逍遥仅在主动进攻战斗前独立判定，默认 60% 概率使张辽所率骑兵攻击增加 35%；非骑兵不获得加成。
- 两项特性独立判定并允许同时触发；防守和增援场景均不得触发。触发概率和效果比例均允许 GM 配置。

### 实现

- 正式配置、特性目录和配置迁移已统一为“震慑全军” `35% / 25%` 与“威震逍遥” `60% / +35%`，清理旧名称、旧 20% 比例和旧最大影响比例字段。
- 震慑全军在战斗核心计算前暂时移出敌方兵力，PVP 与 NPC 结算完成后由既有权威库存链路完整返还；战报结果新增逐兵种 `fledUnits` 与 `returnedUnits`，同时保留历史字段兼容但前端不重复展示。
- `web` 与 `web-wlsg` 同步当前名称、阶段、概率、比例及战报标签；张辽战报明确显示“本场溃逃兵力”和“战后返回兵力”。
- 新增 `docs/系统设计/张辽特性更新开发文档.md`，并同步项目索引、文档目录、现有特性盘点、平衡设计和短期治理文档。

### 验收

- 补充防守、增援、黄巾、NPC、轮回、旧配置迁移、GM 配置和混编总量取整测试；张辽专项使用 Go `-race -count=3` 通过。
