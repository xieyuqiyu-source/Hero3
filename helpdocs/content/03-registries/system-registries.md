# 系统注册表

系统注册表负责核心流程、模块接入和效果扩展。

## 奖励类型注册表

统一识别奖励类型。

常见奖励：

- 资源。
- 金币。
- 城金。
- 道具。
- 兵种。
- 武将。
- 武将经验。
- buff。

副本、邮件、活动、战斗都应该通过奖励系统发奖。

## 事件类型注册表

统一识别事件类型。

常见事件：

- 玩家创建。
- 资源变化。
- 建筑升级。
- 兵力变化。
- 武将变化。
- 奖励发放。
- 战斗结束。
- 邮件领取。

事件用于模块解耦。

## 玩法模块注册表

负责识别已接入的玩法模块。

未来这些都应该是模块：

- 万王争霸。
- 天下名将。
- 轮回绝境。
- 神魔战场。
- 沙巴克。
- 沉冤池。
- 黄巾起义。

## 战斗规则注册表

不同玩法可以使用不同战斗规则。

例如：

- 普通 NPC 战斗。
- 玩家战争。
- 副本战斗。
- 神魔战场。
- 据点争夺。

战斗规则可以不同，但不能各自复制一套不受控的战斗核心。
