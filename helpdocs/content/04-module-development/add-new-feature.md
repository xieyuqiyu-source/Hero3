# 新增功能流程

新增功能时，先判断它是核心能力、内容配置，还是玩法模块。

## 第一步：判断归属

- 长期通用能力：考虑核心。
- 游戏内容：考虑注册表。
- 某个玩法：考虑独立模块。
- 临时活动：考虑活动模块。

## 第二步：确认数据流

需要明确：

- 从核心读取什么。
- 消耗什么。
- 产出什么。
- 是否触发战斗。
- 是否发奖励。
- 是否需要独立状态。
- 是否影响其他玩家或世界。

## 第三步：设计接入点

常见接入点：

- 奖励系统。
- 加成系统。
- 事件系统。
- 战斗规则。
- 数据库权威表。
- API 路由。
- 前端页面。
- 后台配置。

## 第四步：测试

至少验证：

- 成功路径。
- 资源不足。
- 兵力不足。
- 重复领取。
- 异常输入。
- 数据库回写正确。
