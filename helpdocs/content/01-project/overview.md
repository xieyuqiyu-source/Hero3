# 项目总览

Hero3 是一个三国题材 SLG 策略网页游戏。基础循环是：玩家创建存档，升级建筑，积累资源，征兵，出征 NPC 或玩家，获得奖励，再继续发展。

## 项目定位

- 类型：网页 SLG 策略游戏。
- 主题：三国题材，后续可扩展副本、据点、活动、NPC 反攻等玩法。
- 技术形态：前后端分离，后端采用模块化单体。
- 架构方向：稳定核心 + 多模块组装。

## 当前核心目标

- 让核心能力稳定，不随着每个玩法反复改动。
- 让玩法模块通过标准接口接入核心。
- 让资源、兵力、建筑、武将、道具、奖励、加成、事件、战斗都有明确归属。
- 让数据库权威表逐步替代大 JSON 整包读写。

## 你最常查的内容

- 核心是什么：看“核心系统 / 核心边界”。
- 新增资源、兵种、建筑：看“注册表 / 内容注册”。
- 新增副本或据点：看“模块开发 / 玩法接入流程”。
- 数据库慢或字段归属：看“数据库 / 当前权威表”。
- AI 判断规则：看“开发规则 / 项目决策规则”。
