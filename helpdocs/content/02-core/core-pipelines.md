# 核心管线

核心管线是指多个模块都要经过的统一处理链路。

## 奖励管线

所有发奖都应该走奖励系统，例如：

- 副本奖励。
- 邮件附件。
- NPC 战斗掉落。
- 活动兑换。
- 道具使用产出。

奖励管线负责识别奖励类型，并统一回写资源、金币、道具、兵种、武将、经验或 buff。

## 加成管线

加成管线负责把多个来源的加成汇总到统一结果。

常见来源：

- 武将。
- 建筑。
- buff。
- 阵营特性。
- 购买加速。
- 未来活动模块。

## 事件管线

事件管线负责让模块之间低耦合协作。

例如战斗结束后，可以触发：

- 战报生成。
- 奖励发放。
- 任务进度。
- 活动积分。
- NPC 反攻计数。

## 战斗管线

战斗管线负责根据兵种、规则、加成和模式计算结果。

不同玩法可以使用不同战斗规则，但不应该各自复制一套核心战斗算法。
