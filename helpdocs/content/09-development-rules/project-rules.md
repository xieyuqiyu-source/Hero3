# 项目决策规则

稳定规则优先写在根目录 `PROJECT_RULES.md`。

## 为什么不只靠 docs

`docs/` 和 `helpdocs/` 主要是参考和查阅。
真正会影响 AI 开发判断的长期规则，应该写进根目录规则文档。

## 当前关键规则

- 使用中文回答。
- 核心采用模块化单体后端。
- 核心稳定，玩法模块通过标准接口接入。
- 如果出现核心不兼容，要第一时间指出。
- 新需求与旧规则冲突时，先指出冲突，不直接推翻旧规则。
- 每次提交前更新当天 memory。
- 数据库迁移需要用户严格配合。

## 新规则怎么加

当你明确说：

- 记住这个规则。
- 以后按这个判断。
- 加入规则。

就应该把规则写入 `PROJECT_RULES.md`。
