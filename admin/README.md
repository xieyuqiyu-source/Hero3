# Hero3 GM 后台

`Hero3 GM 后台` 是 Hero3 的管理端前端工程，基于 `React + TypeScript + Vite` 搭建，用于对接 Go 后端已暴露的 GM / admin 接口。

## 当前范围

- 后端健康状态读取和账号 / 玩家存档总览。
- 玩家详情查看、资源补发 / 扣减、道具发放、金币和城金调整。
- 玩家世界坐标查看、坐标占用检查、地图占用率查看和世界坐标手动调整。
- 将领洗点、换将、Buff 发放与撤销、小游戏记录查询。
- 信函发送、玩家信函分页查看、附件配置。
- 金币 / 城金流水筛选和汇总。
- GM 配置维护：
  - 建筑数值、升级成本、升级时间、建筑 modifier、加速与兑换参数。
  - NPC 城池全局参数、等级规则、词条池、恢复档案、侦查消耗、城池名池。
  - 战斗规则、场景规则映射、阵营城墙系数和城墙硬度预留参数。
  - 阵营基础信息、阵营 trait、阵营将领列表。
  - 兵种基础信息、属性、训练成本、训练时间和解锁条件。
  - 将领系统开关、经验曲线、等级通用加成、将领基础信息、固定 buff 和特性参数。
  - 仙池垂钓稀有度、鱼饵、鱼池奖励和高级 JSON。
  - 天机轮转每线押注、赔付线、图案权重、倍率、免费旋转、宝匣倍率和高级 JSON。
- 接口诊断、审计规范提示和窄屏后台导航。

GM 接口依赖请求头 `X-Admin-Token`，其值需要和 Go 后端 `HERO3_ADMIN_TOKEN` 环境变量保持一致。后台提供本地 token 面板，保存后刷新页面生效。

使用项目根目录 `./dev.sh` 启动时，脚本会把 `go/.env` 中的 `HERO3_ADMIN_TOKEN` 自动桥接为 `VITE_ADMIN_TOKEN`，本地 GM 后台可直接访问；单独运行 `pnpm dev` 时，需要手动设置 `VITE_ADMIN_TOKEN` 或在后台 token 面板保存。

## 本地开发

安装依赖：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm dev
```

默认地址：

```text
http://localhost:5174
```

构建：

```bash
pnpm build
```

代码检查：

```bash
pnpm lint
```

## 开发约定

- GM 后台是高风险工具，高危操作必须二次确认。
- 玩家长期资产调整必须走后端已有 GM 接口，不在前端绕过核心资产入口。
- 没有后端接口支撑的系统能力，不在前端做假按钮或假成功状态。
- 配置保存以 Go 后端校验结果为准，前端只做结构化编辑和基础输入约束。
- 资源调整、货币调整、邮件发送、配置更新等高风险操作后续必须进入审计日志。
- 页面需要兼容窄屏展示，但后台优先保障桌面端信息密度。
