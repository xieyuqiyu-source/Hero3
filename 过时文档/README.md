# Hero3 过时文档归档

最后更新：2026-07-03

本目录存放已经不再作为当前开发判断依据的历史文档。

归档标准：

- 阶段性开发方案已经完成，并且关键结论已被 README、数据库设计、OpenAPI、当前系统设计或代码吸收。
- 文档描述的是旧阶段实现，和当前代码、`PROJECT_RULES.md` 或最近 `memory/` 记录存在明显差异。
- 排查记录、进度记录或一次性执行文档已经完成，继续留在当前文档目录会干扰后续判断。
- 玩家端帮助正文存在旧口径，当前不适合继续在 `/help` 页面展示。

使用规则：

- 当前开发判断优先看根目录 `PROJECT_RULES.md`、`AGENTS.md`、最近 `memory/`、当前代码、README 和 `docs/` 中仍保留的文档。
- 本目录只用于追溯历史，不作为新需求设计或实现依据。
- 如需恢复某篇文档，先核对当前代码和规则，再移动回对应当前文档目录并更新正文。
