# 基础游戏循环

Hero3 的基础循环是 SLG 策略游戏最重要的地基。

## 主循环

1. 玩家创建账号和存档。
2. 玩家升级建筑。
3. 建筑提高产量、容量、征兵、功能入口。
4. 玩家随时间获得资源。
5. 玩家消耗资源征兵。
6. 玩家派兵攻打 NPC 或玩家。
7. 战斗产生损耗和奖励。
8. 奖励回到玩家核心状态。
9. 玩家继续发展。

## 玩法分支

- 种田玩家：重视产量、仓库、资源田、防守。
- 战争玩家：重视兵力、行军、战斗、掠夺。
- 协防玩家：重视驻防、联盟、防守加成。
- 活动玩家：重视副本、活动、奖励兑换。

不管玩法怎么扩展，最终都要回到核心状态：资源、兵力、建筑、武将、道具、奖励和事件。
