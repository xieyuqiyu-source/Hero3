# 核心边界

Hero3 的核心可以理解成一个稳定 CPU。它不负责每个副本的具体规则，但负责给所有模块提供通用能力。

## 核心负责什么

- 玩家账号。
- 玩家存档。
- 资源和货币。
- 道具和奖励。
- 建筑和基础升级。
- 兵力和基础军事状态。
- 武将持有和基础属性。
- 加成汇总。
- 事件分发。
- 战斗基础规则。
- 存档读写。
- 通知和统一响应。

## 核心不负责什么

- 某个副本的完整玩法规则。
- 某个据点的特殊占领规则。
- 某个活动的排行榜和进度池。
- 某个 NPC 活动的阶段状态。
- 某个玩法特有的世界目标。

这些应该放在玩法模块内部。

## 判断标准

如果这个能力会被很多玩法长期复用，它更像核心。
如果这个能力只服务一个玩法，它更像模块内部逻辑。
