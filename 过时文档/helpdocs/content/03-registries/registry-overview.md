# 注册表总览

注册表的作用是让核心认识可扩展内容，但不把所有内容写死在核心流程里。

## 为什么需要注册表

如果新增一个资源、兵种、建筑、武将或玩法都要改核心代码，核心会越来越乱。
注册表让内容变成“可声明、可发现、可校验”的配置或模块。

## 已有注册表

- 资源类型注册表。
- 奖励类型注册表。
- 事件类型注册表。
- 建筑注册表。
- 兵种注册表。
- 道具注册表。
- 武将注册表。
- 玩法模块注册表。
- 加成 key 注册表。
- 加成来源注册表。
- 武将特性注册表。
- 战斗规则注册表。

## 新增内容时怎么判断

- 新资源：先看资源类型注册表。
- 新奖励：先看奖励类型注册表。
- 新建筑：先看建筑注册表。
- 新兵种：先看兵种注册表。
- 新武将：先看武将注册表。
- 新副本或据点：先看玩法模块注册表。
- 新属性加成：先看加成 key 和加成来源。
